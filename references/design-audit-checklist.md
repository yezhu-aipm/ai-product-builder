# 设计审计清单

> 用在第 4 阶段。逐项检查原型，把发现的问题**编号列出来交给用户勾选**，不要直接改。

每条按这个格式写：`编号｜位置｜现在是什么样｜建议改成什么｜影响（高/中/低）｜工作量`

## 信息与结构
- [ ] 每个页面有没有明确的标题和一句话说明？
- [ ] 主操作在每个页面上是不是只有一个，而且足够显眼？
- [ ] 账号信息、额度、设置、退出的入口好不好找？
- [ ] 当前在哪个页面，导航里有没有高亮显示？

## 列表与内容
- [ ] 长文字有没有截断？截断时有没有省略号和悬停提示？
- [ ] 列表的操作按钮多不多？能不能收进 ⋯ 菜单？
- [ ] 空状态有没有告诉用户下一步做什么？
- [ ] 删除等危险操作有没有二次确认？有没有说明后果？

## 表单与反馈
- [ ] 必填项有没有标注？报错是不是写在出错的那个字段旁边？
- [ ] 按钮在提交中有没有显示忙碌状态？能不能防止重复提交？
- [ ] 能自动识别或默认填写的内容，有没有替用户填好？

## 手机适配
- [ ] 390px 宽度下有没有出现横向滚动？
- [ ] 顶部栏能不能在一行内放下？
- [ ] 表格在手机上有没有改成卡片排列？

## 可访问性与视觉
- [ ] 正文文字的对比度够不够（≥ 4.5:1）？夜间模式也要检查。
- [ ] 按钮、图标有没有 aria-label 或 title？
- [ ] 键盘能不能操作（Tab、Enter、Esc）？
- [ ] 动效会不会卡？快速连续点击会不会卡？

## 一致性
- [ ] 同一个动作，在不同页面用的是不是同一个词？比如统一用"创建副本"，不要有的地方叫"复制"。
- [ ] 图标、圆角、间距是否统一？
