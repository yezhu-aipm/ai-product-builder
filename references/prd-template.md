# PRD 模板

> 用在第 2 阶段。按顺序填，写不出来的地方就是还没想清楚的地方，先回到第 1 阶段补上。

## 1. 背景与目标
- **业务目标**：这个产品最终为哪个业务指标服务？例如家长续费率。
- **产品目标**：用户用完之后，能比现在少做什么、多得到什么？
- **成功指标**：上线后看哪几个数？例如单次生成耗时、需要人工修改的比例、每周使用的老师人数。

## 2. 用户与场景
| 用户 | 场景 | 现在怎么做 | 痛点 |
|---|---|---|---|
| | | | |

## 3. 核心产物
- 最终交付给谁看？长什么样？附上第 1 阶段定下来的样张。
- 产物里的每个模块分别回答什么问题？

## 4. 核心流程
用"第 1 步 / 第 2 步……"写清楚用户从进来到拿到产物的每一步，以及每一步系统做了什么。

## 5. 功能清单
| 功能 | 说明 | 优先级（P0/P1/P2） | 备注 |
|---|---|---|---|

## 6. 数据与计算规则
- **输入**：有哪些材料、支持哪些格式、字段分别是什么。
- **规则**：每一个数字的计算公式和分类阈值。**规则能算的，一律不交给大模型。**
- **大模型负责**：哪些文字由大模型写？字数、语气、禁止写的内容。

## 7. 异常与校验
| 情况 | 等级（必须处理 / 提示） | 系统怎么提示 | 一键修正方式 |
|---|---|---|---|
| 分数超过满分 | 必须处理 | 标红对应格子 | 改为满分 |
| 总分对不上 | 必须处理 | | 以系统合计为准 |
| 识别没把握 | 提示 | 标黄 | 确认 |

## 8. 不做什么
明确列出这一版**不做**的事，防止范围蔓延。

## 9. 隐私与合规
- 涉及哪些个人信息？存在哪里？谁能看到？
- 演示和对外展示用的数据一律虚构。
