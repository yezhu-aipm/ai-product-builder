# 费用控制

> 阿里云**只能提醒，不能自动封顶**。真正的上限只有一个：**账户里只放小额余额**。按量付费的服务扣完余额就会停。

## 必做
1. **绑定邮箱**；在消息中心 → 基本接收管理里，打开"账户资金""费用"两类通知的短信和邮件。
2. **高额消费预警**：费用与成本 → 成本监控 → 成本预警 → 高额消费预警。产品选大模型服务（如百炼），阈值设每天几元。
3. **可用额度预警**：费用与成本 → 账户 → 资金账户 → 可用额度预警 → 修改阈值。
4. 账户余额只充 50～100 元；**不开**信用额度和欠费延停。

## 注意
- 新设的预警规则 **T+2** 生效，也就是两天后。
- 预算管理需要先开通，等 24 小时才能用，功能和预警差不多，可以晚点再设。
- 包年包月的服务器已经付过钱，不会再从余额里扣。
- 网站本身的防线：邀请码、每个账号每月的额度、管理员可以停用账号（见[安全清单](./security-checklist.md)）。
