# 实战中踩过的坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 登录页背景只铺了上半屏 | 外层容器用了 `min-height:100%`，但父元素没有设高度 | 改成 `100vh` / `100dvh` |
| 退出登录后跳到登录页，而不是首页 | 路由守卫读的是旧的地址状态 | 守卫里读当前最新的地址 |
| 用户说"默认颜色不对" | 浏览器记住了用户上次选的主题 | 用无痕窗口验证默认效果 |
| 新服务器上 `unzip: command not found` | 软件列表还没更新 | 先运行 `apt-get update` |
| 粘贴多行命令后没有反应 | 粘贴进去了，但还没执行 | 再按一下回车 |
| 免密登录 Workbench 失败 | 云助手刚开机，还没准备好 | 改用密码认证；如果刚改过密码，先重启服务器 |
| 密钥"已保存"，但其实是空的 | `read` 时没粘贴就按了回车 | 检查长度，并跑一次连通测试 |
| 估错了密钥长度 | 业务空间的密钥比普通密钥长得多 | 以连通测试的结果为准，并向用户更正 |
| Playwright 上传中文名文件失败，而且不报错 | 测试环境的问题 | 测试时把文件复制成英文名再传 |
| `pkill -f` 把自己的 shell 也杀掉了 | 匹配到了自己的命令行 | 改用 pid 文件 |
| Python 3.10 下报语法错误 | f-string 里嵌套了同样的引号 | 换一种引号，并在 3.10 下测一遍 |
| pymupdf 装不上 | 2.x 版本要求 Python 3.11 以上 | 版本要求放宽到 `>=1.24` |
| 自动化测试卡死 | 页面弹出了 alert / confirm | 二次确认改成"再点一次确认" |
| 备份包里没有数据库 | tar 的 `--exclude=app.db` 把备份副本也排除了 | 备份副本换个名字，比如 `app-backup.db` |
